## Aggregate corrections

The first combined run exposed interactions that isolated add-on tests did not:

- the meta candidate pinned AE2 alpha.2 while Ars Énergistique alpha.1 requires
  the already published AE2 alpha.3 registration API;
- FramedBlocks alpha.1 admitted the preceding BlueMap backport identity rather
  than the current, ABI-equivalent ATMons 1.2.0 backport;
- Camol alpha.1 wrapped every variant during its unordered bake callback and
  could overwrite custom renderers installed later by other add-ons; and
- malformed animation metadata in the installed Integrated Dynamics JAR
  aborted BlueMap's texture pass before the valid cable texture.

That earlier tagged snapshot pinned AE2 `0.1.0-alpha.3` plus FramedBlocks,
Camol, and Integrated Dynamics `0.1.0-alpha.2`. The second cold start and
render used those corrected artifacts; Ars Énergistique remained at its
compatible `0.1.0-alpha.1` release.

This is a combined compatibility and representative-render gate, not a
pixel-level comparison of every supported block and not a production-server
deployment claim.
